# Roadmap

## 0.1 — Working preview

- Modern Windows UI and interactive canvas
- Multiple series, spreadsheet import, axis editing, best-fit lines
- Save/open native documents
- Read common legacy `.ograph` graphs
- SVG and CSV export
- Automated Windows packages

## 0.2 — Drawing parity

- Freehand strokes and filled regions
- Arrowheads, dashed lines, custom point shapes, and grouping
- Richer text editing and label attachment
- Snapping, marquee selection, and multi-element transforms

## 0.3 — Data parity

- Error-bar generation tools
- Equation plots, additional regressions, histograms, and summary statistics
- Full data mapper behavior for headers and categorical columns
- Complete clipboard interchange

## 0.4 — Interoperability

- Round-trip all supported `.ograph` elements without losing unknown XML
- Preview image inside zipped `.ograph` documents
- PDF and high-resolution PNG/JPEG export
- Golden rendering comparisons against representative original documents

## 1.0 — Stable Windows release

- Keyboard-only and screen-reader accessibility pass
- Localization infrastructure
- Signed installer and update channel
- Document migration guarantees and a published compatibility policy
- Upstream review or explicit continuing independent-port status
